Reverting to RHEL 9.4 Kernel Version (After Upgrade to RHEL 9.5)

By A.M. Rinas Published May 30, 2026 Category: Tech 4 min read

After a RHEL minor-version upgrade, the system boots the newest kernel by default. If your workload (drivers, security tooling, or applications) is not yet certified for the new kernel, you can boot the previous RHEL 9.4 kernel instead — while keeping the upgraded packages installed.

  • Current Kernel Installed: 5.14.0-427.42.1.el9_4 (RHEL 9.4)
  • Available Kernel Versions: Includes 5.14.0-503.x.x.el9_5 (RHEL 9.5) and multiple 5.14.0-427.x.x.el9_4 (RHEL 9.4)

Steps to Revert to a RHEL 9.4 Kernel Version

1. Install the Desired Kernel Version from RHEL 9.4

Install the exact kernel version you want to run:

sudo dnf install kernel-5.14.0-427.33.1.el9_4

If you are unsure which 9.4 builds are available, list them from the repository first: 

dnf list available kernel --showduplicates | grep el9_4

2. Reboot the System to Apply the New Kernel

sudo reboot

GRUB boots the highest-version kernel by default, so a newly installed 9.4 kernel will be selected over the 9.5 one. If the system still boots the 9.5 kernel, pick the 9.4 entry manually from the GRUB boot menu.

3. Verify the Kernel Version

uname -r

Expect output similar to 5.14.0-427.33.1.el9_4.x86_64.

4. Make the Choice Permanent (Optional)

To prevent the 9.5 kernel from being used again until you are ready, pin the installed 9.4 kernel so dnf does not upgrade it away: 

sudo dnf install -y dnf-plugin-versionlock
 sudo dnf versionlock add kernel-5.14.0-427.33.1.el9_4

Remove the lock later with sudo dnf versionlock delete kernel-5.14.0-427.33.1.el9_4 once you move back to 9.5.
